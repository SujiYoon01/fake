인원월보 대시보드를 만들어 주세요. 아래 조건을 지켜 주세요.

■ 형식
- 단일 HTML 파일 하나(CSS·JS 인라인, 외부 라이브러리 없이 순수 JS + SVG)로 만들어 주세요.
- 서버 없이 브라우저에서만 동작해야 하며, 업로드한 CSV는 외부로 전송하지 마세요.
- 코딩을 모르는 사용자가 매달 수정할 값은 파일 상단 "설정 상수" 영역에 모으고, 한국어 주석을 달아 주세요.

■ 입력
- 당월 명부 CSV(필수)와 전월 명부 CSV(선택)를 업로드합니다. UTF-8(BOM 포함 가능)만 지원하고, 읽기 실패 시 안내문을 표시해 주세요.
- 필수 컬럼: 사번, 성명, 재직상태(재직/휴직), 원소속부서, 법정생년월일, 최종학력, 직급코드, 사업장, 직위코드명
- 선택 컬럼: 직급명, 직책코드명, 근무지역, 그룹입사일(YYYYMMDD), 파견조직코드명, 휴직구분명
- 필수 컬럼이 없으면 빠진 컬럼명을 화면 상단에 빨간 글씨로 알려 주세요.

■ 설정 상수(코드 상단에 분리)
- ORG_FIELD: 부서 집계 기준 컬럼(기본 '원소속부서')
- BU_ORG_MAP: 사업부(DE, 우주, 해양, MRO, 기반연구소, 구미사업장, 지원조직, 기타)별 소속 팀 목록
- ORG_GROUPS: 우주사업부 내부 그룹(직속조직, 연구소)별 팀 목록
- 임원 직위: 임원·전무·상무·부사장·고문
- 직급코드 해석: 영문 직군 + 숫자 레벨(R4 → R직군 L4). SM은 S로 합산, TJ·TA·TS는 T직군 L3, 레벨 3·2·1은 "L3이하"로 합침
- 학력: 박사 / 석사 / 학사이하(학사·전문대·고교·빈칸), 빈칸 인원 보정 목록 EDU_OVERRIDES
- 조직장 수동 지정 HEAD_OVERRIDES, 강제 전입 이름 FORCE_TRANSFER_IN
- 기준일: 제목의 'YY.MM에서 말일로 자동 계산(날짜 입력창은 숨김)

■ 화면
- 상단: 제목('YY.MM 인원현황), 업로드 영역(상태 표시), [현재 화면 HTML로 저장] 버튼, 탭 "① 우주사업부 현황" / "② 전사·사업부 비교"

① 우주사업부 현황 (지정한 팀 소속만 집계, 상위조직 제외)
- KPI: 재직 인원(임원 제외, 전월 대비 증감), 발령·변동 건수, 평균 근속연수(임원 제외)
- 카드: 인력증감내역(채용·복직·전입·퇴직·휴직·전출 막대, 클릭 시 명단), 채용·퇴직 / 전입·전출 / 전배·조직개편·직급변동·사업장이동·근무지이동 상세표, 부서별 인원현황(타일+도넛, 클릭 시 조직장), 사업장별 인원(도넛, 조각 클릭 시 소속 부서), 부서별 레벨 분포(교차표+합계), 부서별 레벨 피라미드(클릭 시 상세), 직급별 인원, 직군별 인원(도넛), 조직별 학력(표+도넛), 부서별 평균 근속연수, 근속연수 구간별 인원(0~4, 5~9, 10~14, 15~19, 20~24, 25년 이상)
- 임원 제외 카드는 우측 상단에 '임원 제외'를 표시해 주세요.
- 인력 변동 규칙: 전월에 없던 사번은 입사연월이 당월이면 채용, 아니면 전입. 특정 팀→특정 팀 이동은 '전배' 대신 '조직개편'으로 표기(상수로 지정).

② 전사·사업부 비교
- KPI: 전사 재직 인원, 평균 근속연수
- 카드: 사업부별 인원(도넛), 평균 연령(한국나이), 임원현황, 임원 1인당 관할인원, 학력분포(표+도넛), 레벨 피라미드
- 어느 사업부에도 속하지 않는 소속은 '사업부 미분류 N명: 이름(소속)'으로 표시해 주세요.

- 카드마다 합계가 서로 일치해야 합니다.
- 도넛 라벨은 카드 밖으로 나가지 않게 해 주세요.
- 완성 후 가상 CSV로 직접 테스트하고, 오류가 없는지 확인한 결과를 알려 주세요.
