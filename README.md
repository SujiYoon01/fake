[역할]
당신은 HR 데이터를 다루는 프론트엔드 개발자입니다. 코딩을 전혀 모르는 HR 담당자가 사용할 예정이므로, 설치 없이 더블클릭만으로 열리는 "단일 HTML 파일"(HTML+CSS+바닐라 JS, 외부 라이브러리·CDN 사용 금지, 오프라인 동작)로 "근무실적 현황 대시보드"를 풀코드로 만들어 주세요. 주석은 한국어로 작성하시고, 차트는 모두 SVG/CSS로 직접 그려 주세요.

[목적]
매월 근태 로우데이터 CSV를 업로드하면 조직장에게 보고할 수 있는 근무시간 현황이 자동으로 집계되는 대시보드입니다. 데이터는 파일 밖으로 전송하지 않고 브라우저 안에서만 처리해 주세요.

[입력 CSV]
- 열: No., 구분, 년월(예: 202609), 주차(예: "3주차"), 사번, 이름, 직급, 사업장, 부서명, 월, 화, 수, 목, 금, 토, 일, 주확정근무시간, 평일확정근무시간, 법정휴게시간, 비업무_기타, 비업무, 비업무(중식)
- 1행은 1명의 1주차 데이터입니다. 월~일, 주확정근무시간 등은 "분(minute)" 단위이므로 화면에는 시간(÷60)으로 표시해 주세요.
- 파서: 따옴표 안전 처리를 직접 구현해 주시고, 쉼표/탭 구분자 자동 감지, BOM 제거, 인코딩 자동 감지(UTF-8 → 실패 시 EUC-KR, UTF-16 BOM 처리)를 지원해 주세요.
- .xlsx(zip 시그니처 PK)를 올리면 "CSV UTF-8로 저장 후 다시 올려 주세요"라는 오류 배너를 표시해 주세요. 필수 열이 없으면 누락된 열 이름을 배너로 안내해 주세요.

[집계 대상/제외 규칙] (코드 상단 상수로 분리하여 쉽게 수정할 수 있게 해 주세요)
- 대상 부서: RESEARCH_DEPTS = ['부서A','부서B', ...] (이 부서만 집계하며, 이 배열의 순서가 모든 화면의 정렬 순서입니다)
- 제외 대상: 구분이 '근태예외자'인 경우, 직급이 상무/전무/부사장인 경우, 주확정근무시간이 0인 주차
- 부서 병합 맵(DEPT_MERGE)도 상수로 제공해 주세요.
- 주차 키: 년월 + 주차 숫자(2자리)로 정렬해 주세요.
- 월 집계: 최신 년월을 "이번 달"로 보며, 개인별 월 평균 주간 확정근무시간은 해당 월 주차들의 평균으로 계산해 주세요. 요일별 평균은 0분인 날(휴가)을 제외하고 평균을 내며, 토·일은 전체 주 평균으로 계산해 주세요.
- 52시간 이상 판정은 52시간 이상(>= 52, 시간 기준)입니다.
- 위험군은 가장 최근 주차부터 거꾸로 세어 52시간 이상이 2주 이상 연속인 인원입니다. 전월 CSV가 있으면 전월 주차까지 이어서 계산해 주세요.

[상단 영역]
- 버튼: "CSV 불러오기", "전월 CSV 불러오기"(전월 비교용), "완성 파일로 저장", "현재 선택 필터 내용 저장"
- 부서 드롭다운(전체 + 대상 부서들), 데이터 상태 문구, 전월 데이터 첨부 상태 문구
- 탭 2개: [근무실적 현황] [사분면 분포]

[근무실적 현황 탭 – 카드 구성]
1. 인원 검색: 이름 부분일치 검색을 지원하고, 동명이인이면 "이름.부서.직급" 버튼으로 선택할 수 있게 해 주세요. 결과 카드에는 이번 달 평균, 부서 평균 대비 편차, 전체 평균 대비 편차, 최근 6주 주별 근무시간(52시간 이상은 빨간색), 연속 52시간 주수 태그를 표시해 주세요. 초기화 버튼도 넣어 주세요.
2. KPI 4개: (a) 이번 달 평균 52시간 이상 인원 수·비율(도넛 차트, 전월 대비 %p, 부서 선택 시 전체 비율 병기) (b) 위험군 인원(4주 연속 인원, 전월 대비 증감) (c) 평균 주간 확정근무시간(52시간 대비 여유) (d) 주말 근무 발생 인원(토 N · 일 N · 중복 N, 합집합 기준)
3. 주별 52시간 이상 근무자 비율 추이: 최근 8주 꺾은선 차트이며, 각 점에 (비율%, 인원명) 라벨을 표시해 주세요. 부서 선택 시 점을 클릭하면 해당 인원 툴팁이 뜨게 해 주세요.
4. 부서별 평균 주간 확정근무시간: 가로 막대 차트이며, 전체 평균 점선과 전월 대비 ▲▼ 표시를 넣어 주세요. 부서 선택 시에는 "해당 부서 vs 전체 평균" 2개 막대로 보여 주세요.
5. 근무시간 현황 표: 전체 선택 시 "52시간 근무자"를 조직도순으로, 부서 선택 시 해당 부서 전원을 근무시간 내림차순으로(순위 열 포함) 표시해 주세요.
6. 주 근무시간대별 인원 분포: 파이차트(40~42, 42~44, 44~46, 46~48, 48~50, 50~52+)입니다. 조각을 클릭하면 부서별 명단 툴팁이 뜨고, 다시 클릭하면 닫히게 해 주세요.
7. 평일 요일별 근무시간 편차: 월~금 평균이 평일 평균 대비 위/아래로 벌어지는 발산형 막대 차트이며, 값 라벨은 소수 2자리로 표시해 주세요.
8. 주말 근무 현황: 토/일 각각의 인원·평균 시간을 보여 주고, 클릭하면 부서별 명단이 펼쳐지게 해 주세요.
9. 위험군 상세 표: 이름·부서·직급·연속 주수 태그(2주/3주/4주+ 색 구분)·최근 주 근무시간을 표시해 주세요. 정렬은 조직도순 → 연속 주수 → 근무시간 순입니다.
10. 위험군 변동(전월 대비): 신규 진입 / 이탈을 부서별 접이식 목록(인원수 + 화살표 클릭 시 명단)으로 표시해 주세요. 전월 CSV가 없으면 안내 문구를 보여 주세요.
- 모든 카드 제목 옆에 ⓘ 버튼을 두고, 클릭하면 모달로 카드 설명이 표시되게 해 주세요.

[사분면 분포 탭]
- x축은 이번 달 평균 근무시간, y축은 평균 대비 편차입니다. 부서 전체 선택 시에는 부서별 점(크기는 인원)으로, 특정 부서 선택 시에는 근무시간이 ±0.3시간 이내로 비슷한 사람끼리 묶은 점으로 표시해 주세요. 점 클릭 시 명단 툴팁이 뜨게 하고, 평균 기준 점선과 색 범례도 넣어 주세요.

[저장 기능]
- "완성 파일로 저장": 현재 HTML 전체를 복사하되, 코드 안의 `const EMBEDDED_CSV = \`\`;` 자리에 현재 CSV 텍스트(백틱·백슬래시·${ 이스케이프 처리)를 끼워 넣어 다운로드되게 해 주세요. 이 파일은 열자마자 데이터가 표시되어야 합니다(전월 CSV도 EMBEDDED_PREV_CSV로 동일하게 처리).
- "현재 선택 필터 내용 저장": 선택한 부서의 행만 임베딩한 팀장 배포용 HTML을 생성해 주세요. 이때 부서 필터를 적용하기 전의 "전체 평균·52시간 이상 비율"을 계산해 EMBEDDED_ORG_STATS로 함께 저장하여, 팀 파일에서도 전체 대비 비교가 유지되게 해 주세요. 부서가 1개뿐인 파일은 드롭다운에서 '전체' 옵션을 숨겨 주세요.

[디자인]
- 톤: 네이비 #1E3358, 스틸 #53728A, 스카이 #7691AD, 페일 #B9CFDD, 경고 코랄 #C0392B, 배경 #EEF3F7, 흰색 카드(둥근 모서리 22px, 옅은 그림자), 폰트는 Malgun Gothic입니다.
- 근무시간 색 단계(공통): 42 미만 페일 / 42~44 연하늘 / 44~46 스카이 / 46~48 진한 스카이 / 48~50 스틸 / 50 이상 코랄. 색 판정 전에 소수 1자리로 반올림한 값을 사용해 주세요.
- 숫자 표기는 소수 1자리(요일 편차만 2자리)로 통일하고, 반응형(900px 이하에서는 1열)으로 만들어 주세요.

- 같은 사람이 여러 부서로 나오지 않도록 사번 기준으로 집계해 주세요.
- 완성 후 샘플 데이터 몇 줄로 계산이 맞는지(월평균, 52시간 이상 판정, 위험군 연속 주수) 스스로 점검해 주시고, 수정이 필요한 위치는 "Ctrl+F로 찾을 문장 → 바꿀 문장" 형식으로 안내해 주세요.
