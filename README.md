# 우주사업 KPI & HR Calendar 대시보드 제작 프롬프트

> 사용 모델: Claude (Anthropic) Sonnet 5.5 · 결과물: 단일 HTML 파일

---

## 역할
당신은 시니어 프론트엔드 엔지니어입니다. HR 담당자가 현업에서 바로 사용할 수 있는 "연간 사업 KPI & HR 스케줄 대시보드"를 HTML 파일 하나로 만들어 주세요.

## 배경
- 사용자는 방산기업 우주사업부 HRBP이며, 코딩 경험이 없습니다.
- 현재 엑셀로 관리 중인 "가로형 연간 KPI 및 HR 스케줄"을 웹 대시보드로 옮기려고 합니다.
- 팀장님과 팀원들이 PC, 휴대폰, 아이패드에서 링크 또는 파일로 열어 한눈에 확인하는 리포트입니다.

## 화면 구조 (왼쪽 → 오른쪽)
대분류 | 구분(그룹명 + 소구분) | 가중치 | 목표 | 세부내용 | 월별 타임라인(2월~12월, 11개월)

- 대분류는 "사업부 KPI"와 "HR Calendar" 2개이며, 색상으로 구분해 주세요.
- 같은 그룹·목표는 셀 병합(rowspan)으로 표현하되, 열 정렬이 어긋나지 않도록 실제 `<td>` 기반으로 작성해 주세요.
- 일정은 월 칸에 막대(칩)로 표시하고, 여러 달에 걸치면 병합하며, 핵심 일정은 강조색으로 표시해 주세요.
- 여러 행에 걸친 세로 병합 칩도 지원해 주세요.

## 핵심 기능
1. 대분류 필터(전체 / 사업부 KPI / HR Calendar)와 텍스트 검색
2. 그룹 접기/펼치기
3. "이번 달 주요 일정" 패널: 기기 날짜 기준으로 표시하고, 클릭하면 해당 일정으로 이동·강조
4. 일정 칩 클릭 시 상세 카드(팝업) 표시
5. 소구분 클릭 시 등급별(S/A/B+/B/C) 달성 기준 카드 표시
   - 항목에 따라 카드가 1~4개 동시에 뜨며, 서로 겹치지 않게 화면 중앙에 세로로 정렬해 주세요.
   - 카드의 어느 부분을 잡아도 드래그로 이동할 수 있게 해 주세요.
   - 가로·세로 스크롤 없이 한 화면에 모두 보이게 해 주세요.
6. "연말 달성 전망" 신호등: 목표 칸에 초록/노랑/빨강 버튼을 두고 클릭할 때마다 순환하게 해 주세요. 상단 원형 게이지(위성 아이콘)에는 가중치를 반영해 자동으로 집계해 주세요.
   - 신호등은 "현재 진척도"가 아니라 "연말까지의 달성 가능성"을 의미합니다.
   - 배포용 기본값은 코드에 지정하고, 사용자가 바꾼 값은 브라우저에 저장해 주세요.
7. 인쇄/PDF 출력 기능

## 디자인 가이드
- 차분한 업무용 톤으로, 웜 크림 배경에 사업부 KPI는 티얼, HR Calendar는 플럼 계열, 강조색은 연한 카키로 해 주세요.
- 현재 달 칸은 옅은 음영으로 표시해 주세요.
- 모바일/태블릿(가로 모드)에서도 레이아웃이 깨지지 않게 하고, 화면이 넓으면 표가 빈 공간 없이 꽉 차게 해 주세요.

## 기술 제약
- 외부 라이브러리 없이 순수 HTML/CSS/JS 한 파일로 작성해 주세요. (폰트만 Google Fonts 허용)
- 데이터는 JS 배열(`ROWS`)로 분리해, 비개발자도 값만 고쳐서 수정할 수 있게 해 주세요.
- 이후 수정 요청 시에는 전체 코드 대신 "Ctrl+F로 찾을 문구 → 바꿀 문구" 형태로 일부만 안내해 주세요.

## 진행 방식
- 먼저 구조와 데이터를 확정한 뒤, 디자인과 기능을 단계별로 추가해 주세요.
- 매 수정 후 실제 브라우저로 렌더링해서 정렬·겹침·스크롤 여부를 확인하고 결과를 알려 주세요.
